1. Estructura Semántica de HTML5 y Estilos CSS

Las etiquetas semánticas definen la estructura clara del documento web y mejoran la accesibilidad y el SEO.

Etiquetas Principales

<header>
Define el encabezado de un documento o sección (logo, títulos y buscador)[span_3](start_span)[span_3](end_span).
<nav>
Agrupa los enlaces de navegación principal[span_4](start_span)[span_4](end_span).
<main>
Define el contenido principal único del documento (solo uno por página)[span_5](start_span)[span_5](end_span).
<section> / <article> / <aside>
Agrupan contenido temático, independiente o lateral[span_6](start_span)[span_6](end_span).
<footer>

3. Media Queries, Flexbox y Grid

Media Queries (@media)

Permiten aplicar estilos según las características del dispositivo o pantalla para adaptar páginas a computadoras, tabletas y celulares[span_18](start_span)[span_18](end_span)[span_19](start_span)[span_19](end_span).

  body { background-color: lightblue; }
}

Flexbox (display: flex)

Modelo de diseño unidimensional para organizar, alinear y distribuir elementos de manera flexible dentro de un contenedor en filas o columnas[span_20](start_span)[span_20](end_span).

CSS Grid (display: grid)

5. El DOM (Document Object Model) y Métodos de Selección

Estructura que representa el documento HTML como un árbol de objetos, permitiendo a JavaScript modificar elementos sin recargar la página[span_34](start_span)[span_34](end_span)[span_35](start_span)[span_35](end_span).

getElementById()

Busca y selecciona un elemento HTML por su atributo id[span_36](start_span)[span_36](end_span)[span_37](start_span)[span_37](end_span).

document.getElementById("id").innerHTML = "Texto";

querySelector()

Selecciona el primer elemento que coincida con un selector CSS (clase, ID o etiqueta)[span_38](start_span)[span_38](end_span).

document.querySelector(".clase").style.color = "red";

Otros Métodos del DOM

  • getElementsByClassName(): Selecciona por clase[span_39](start_span)[span_39](end_span)[span_40](start_span)[span_40](end_span).
  • getElementsByTagName(): Selecciona por etiqueta (ej. <p>)[span_41](start_span)[span_41](end_span).
  • getElementsByName(): Selecciona por atributo name[span_42](start_span)[span_42](end_span).
  • innerHTML / textContent: Modifican contenido HTML o texto plano[span_43](start_span)[span_43](end_span).
